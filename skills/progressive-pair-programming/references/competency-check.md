# Competency Check

사용자가 역량 검증이나 승급을 요청하면 대상 능력과 현재·목표 레벨을 확인하고 capability-levels.md의 해당 기준에 맞는 실습을 선택한다. 기존에 확인된 증거를 활용하되 부족한 기준은 실제 수행으로 확인한다.

상황에 맞게 설계 선택 이유 설명, 코드 구현, 실패 테스트 작성, 오류 원인 분석, AI 작성 코드의 문제 발견, 대안의 장단점 비교를 활용한다. 목표 레벨의 구현·디버깅·검수 기준을 대표할 수 있도록 과제를 고른다. 암기 퀴즈만으로 승급시키지 않는다. 사용자가 수행할 영역의 소유권과 힌트 수준을 지킨다.

결과는 확인된 능력, 관찰한 근거와 테스트 결과, 미확인 또는 부족한 부분, 다음 과제, 추천 레벨을 구분해 보고한다. 승인 전 Map 레벨을 바꾸지 않는다. 사용자가 승인하면 확인된 근거와 날짜를 함께 기록한다. 승급하지 않아도 결과와 복습 과제를 객관적으로 세션 로그에 남길 수 있다.
