# Delegation and evidence

레벨은 기술 이름 전체가 아니라 구체적인 구현 능력과 이번 작업의 영역에 적용한다. Map의 과거 레벨은 제안의 근거이며 현재 작업의 소유권을 사용자와 정한다.

- L0 Human Driver: 사용자가 설계, 테스트, 핵심 구현을 수행한다. AI는 요구사항 분석, 질문, 설계 문제 지적, 리뷰, 점진적 힌트, 실패 원인 분석을 지원한다. 사용자 요청 없는 완성 코드와 무단 파일 수정은 금지한다.
- L1 Guided Collaboration: 사용자가 핵심 로직을 주도한다. AI는 승인된 범위의 보일러플레이트, 테스트 구조 제안, 인터페이스·스캐폴딩, 부분 코드, 리팩터링 방향을 지원한다.
- L2 Supervised Delegation: 사용자가 요구사항, 불변식, 테스트 기준을 정의한다. AI는 승인 범위에서 구현하고 테스트 작성·실행, 설계 근거, 변경 및 트레이드오프를 보고한다. 사용자가 결과와 테스트를 검증하고 최종 승인한다.
- L3 Bounded Autonomous Delegation: AI가 승인 범위에서 설계 세부화, 구현, 테스트, 리팩터링을 수행한다. 별도 승인 경계는 SKILL.md에 따른다. 사용자가 결과를 검수한다.

승급 제안의 최소 근거:

- L0 → L1: 대표 기능을 직접 구현하고 핵심 메커니즘을 설명한다.
- L1 → L2: 정상·실패 시나리오를 테스트하고 대표 오류를 직접 디버깅하며 주요 트레이드오프를 설명한다.
- L2 → L3: AI 결과를 독립적으로 검수해 요구사항 누락과 설계 위험을 찾고 실패 시 수정 방향을 결정한다.

횟수나 자기평가만으로 승급하지 않는다. 근거가 부족하면 미검증으로 기록하고 다음 도전을 제안한다. 근거와 추천 레벨을 보여 준 뒤 사용자가 승인할 때만 Map의 레벨을 수정한다. 새 실패는 복습 과제의 근거가 될 수 있다.
